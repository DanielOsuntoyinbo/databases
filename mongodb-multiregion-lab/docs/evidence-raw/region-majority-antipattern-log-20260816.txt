--- Analysis ---

Same failure signature as the section-6 even-vote partition test
(NotWritablePrimary, repeated correct election refusal), but a
different root cause: total vote count here is 5 (odd), yet the
outage of a single region (Ireland, holding 3-of-5 votes outright)
still took the whole cluster's write availability with it. Proves
odd total vote count is necessary but not sufficient — the real
safety property is "no single failure domain holds a majority by
itself," which this 2+3 topology violates despite having an odd total.
